# 数据库复现材料

本目录用于复现多数据库图书管理系统的隔离测试数据。所有账号、手机号、图书和读者均为合成数据，不包含原数据库导出内容、连接口令或个人信息。

## 目录

- `mysql/`：MySQL 8.x 表结构和初始化脚本
- `sqlserver/`：SQL Server 2019+ 表结构和初始化脚本
- `postgresql/`：PostgreSQL 14+ 表结构和初始化脚本
- `snapshots/`：借阅、归还及并发缺陷的脱敏数据快照

三套脚本均建立 `books`、`readers`、`borrows`、`users`、`sync_logs` 五张表。初始化后应得到 3 个测试账号、3 本测试图书、2 名测试读者和 0 条借阅记录。

## 安全使用

1. 先创建独立测试库，例如 `book_manage_test_demo`。
2. 明确选中测试库后再执行对应 `schema.sql` 和 `seed_test.sql`。
3. 不要对原 `book_manage` 数据库执行这些脚本。
4. `seed_test.sql` 只清理以 `QA_PUBLIC_` 开头的合成记录，便于重复执行。

公开脚本中的密码仅用于本机测试，不能用于真实系统。快照是根据实际测试前后数据整理的脱敏证据，保留了判断通过或失败所需的关键字段。
